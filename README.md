# 次軌道載具設計工作單

互動式教學工作單,說明設計一個「太空港到太空港」的次軌道飛行系統時,
工程因子如何彼此耦合 —— 以及模擬工具的能力邊界在哪裡。

給大學工程背景的學生使用。

## 定位

這是**長程次軌道／高超音速跨洲飛行**的概念分析與模擬工具邊界辨識教材,
**不是**民用次軌道觀光飛行器(80–120 km 高度、數百公里射程)的設計模型,
也不是「次軌道載具設計計算器」。

預設航線 13,109 km,採**淺角度助推滑翔**:熄火於卡門線附近(γ = 2°)、
遠地點約 **107 km**,之後全程靠升力滑翔。
所有數值是一階概念估算,**不是設計值**。

> 初版用最小能量彈道,算出遠地點 **1,130 km** —— 是卡門線的 11 倍。
> 每個數字都對,組合起來卻是一條沒有有翼載具會飛的軌跡。
> 那個錯誤與它的修正記錄在設計文件的 2.4 與 6.4 節。

## 這頁想解決的教學問題

講這個題目最容易做成「公式清單 + 靜態圖表」,學生會把每個公式當成獨立的
知識點記下來。但真正的設計困難在於**這些因子彼此耦合,不能各自最佳化**。

所以整頁的骨幹是一條推導鏈:八個設計變數(射程、升阻比、翼負荷、
兩節比衝、Δv 分配、推重比、損失假設),動任何一個,
七個步驟的數字同時重算。

    射程 → 中心角 → 純彈道所需速度 → 淺角度助推滑翔
         → Δv 預算 → 質量比(指數關係)→ 燃燒時間與分離時刻
         → 再入條件與工具邊界

## 四個刻意安排的教學時刻

| 針對的迷思 | 呈現方式 |
|---|---|
| 「加機翼一定有利」 | 助推滑翔曲線與純彈道基準線在 **L/D ≈ 1.61** 交會;低於此機翼是淨負擔 |
| 以為工具限制與設計無關 | 同一張圖上 **L/D ≈ 6.54** 時所需速度降到求解上限以下,**模型接縫消失** |
| 低估 Δv 對質量比的敏感度 | 對數縱軸上兩節式是一條直線;旁邊是同樣 Δv 用單節做的曲線 |
| 以為模擬工具涵蓋全程 | 軌跡剖面上的**再入減速帶**沒有任何現成模型涵蓋,畫得和其他三段一樣顯眼 |

最後兩項是這頁最想傳達的東西。工程模擬裡「模型邊界」的存在是常態,
但教材通常只給一條看起來完美的軌跡,學生因此不知道要去問邊界在哪 ——
更不會想到那個邊界可以反過來當成設計指標。

## 動畫、3D 外型與流場

**滑翔與降落動畫**:按播放,看載具從交接點滑到跑道。姿態儀顯示俯仰角 θ、
速度向量(飛行路徑角 γ)與兩者夾角的攻角 α。高超音速段 γ 只有 −0.06° 而
α 有 14° —— **載具是機頭朝上在下降的**,升力來自機體迎風面。

迎風面依**輻射平衡壁溫**上色(Sutton–Graves 熱通量 + `q = εσT⁴`,
機腹/駐點比例以太空梭實測錨定)。峰值 1,175 °C,太空梭機腹中線實測約 1,260 °C。

外層紅暈是**電漿鞘**。高速下激震層空氣游離,自由電子把電波反射掉 ——
遮蔽條件是電漿頻率高於訊號頻率,所以頻率愈高愈穿得過去:

| 頻段 | 恢復通訊 | 遮蔽時長 |
|---|---|---|
| UHF 400 MHz | 2,690 m/s | 25.8 min |
| S 2.2 GHz | 3,260 m/s | 21.3 min |
| X 8.4 GHz | 3,921 m/s | 15.6 min |
| Ka 26 GHz | 4,758 m/s | 7.5 min |

(太空梭 S 頻實測 12–16 分鐘,同一量級。)

**真實空速與對地速度**的時程圖:兩者在高超音速段幾乎重合(γ 只有 0.06°,
水平分量就是全部),到 TAEM 才明顯分開。本模型無風。

**3D 外型**:參數化建模產生的網格(10,644 面),與 STK 場景用的是同一份,
可拖曳旋轉。三種著色:零件材質、修正牛頓流壓力係數、迎風面熱通量。

> **關於 Mach 20 的流場。** 這不是 CFD。能做 Mach 20 非平衡流的開源工具是
> SU2-NEMO、hy2Foam、COOLFluiD、Eilmer,都需要網格生成與熱化學庫,
> 跑不進瀏覽器。這裡用的是**修正牛頓流撞擊理論** ——
> `Cp = Cp_max·sin²δ`,而 `Cp_max → 1.839`(γ=1.4 極限)。
> 它在 Mach 20 比在 Mach 3 **更**站得住,因為馬赫數獨立原理。
> 不含邊界層、尾流、震波脫體距離與真實氣體效應。

## 乘波體、錢學森彈道、桑格爾彈道

這三個名詞常被混用,但**乘波體是「外型」,另外兩個是「軌跡」** ——
乘波體與錢學森彈道不是替代關係,前者正是後者需要的高升阻比的來源。

| | 是什麼 | 高度剖面 |
|---|---|---|
| 乘波體 | 氣動外型:前緣騎在自己的震波上 | — |
| **錢學森彈道** | 單次再入後**持續**平衡滑翔 | 單調下降(**本頁採用**) |
| 桑格爾彈道 | 反覆進出大氣層 | 振盪 |

頁面附三者的軌跡對照圖(縱軸平方根尺度,否則純彈道的 1,189 km 遠地點
會把另外兩條壓成一條線)。一階模型算出桑格爾同樣熄火速度下射程**反而較短**,
而且反覆的熱脈衝對熱防護更嚴苛。

## 四層狀態

頁面把設計點的狀態分開顯示,因為這四件事常被混為一談:

| 層 | 判定 |
|---|---|
| 數學可算 | 所有輸出為有限值 |
| 模型適用 | 平衡滑翔未退化、短弧解成立、推重比 > 1、質量比 < 20 : 1 |
| 模擬工具 | 所需速度是否超出航段求解器的收斂範圍 |
| 工程可行 | **恆為「未驗證」** |

第四層刻意寫死,不隨參數變化 —— 無論參數怎麼調,要判斷可行性都還需要
上升段軌跡最佳化、含阻力與升力的六自由度再入積分、氣動係數資料庫、
熱防護與結構分析,以及控制系統設計。本頁一項都沒有。

## 計算依據

最小能量彈道解(球形地球、無阻力)、Eggers 理想化平衡滑翔射程、
齊奧爾科夫斯基方程、Sutton–Graves 熱通量比例式的速度項。

每一條公式的假設、適用範圍與失準處寫在
[`web/設計與計算原理.md`](web/設計與計算原理.md),
包含兩個在撰寫該文件時才發現的數值錯誤(地球半徑常數不一致、
損益平衡點畫在一條永遠不會相交的曲線上)。

## 執行

工作單是單檔 HTML,可直接用瀏覽器開啟
[`web/suborbital_workbench.html`](web/suborbital_workbench.html),
不需要任何伺服器。

Streamlit 版本只是部署外殼(取得公開網址、提供下載),
不是原生 Streamlit app —— 理由與取捨寫在 `streamlit_app.py` 的 docstring。

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

### 部署到 Streamlit Community Cloud

```
Branch          main
Main file path  streamlit_app.py
```

相依由根目錄的 `requirements.txt` 自動讀取(只有 `streamlit` 一項),
不需要在 Advanced settings 另行指定。
